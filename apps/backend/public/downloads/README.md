# Thư mục lưu trữ file APK phát hành của Tiên Lộ

Bạn có thể đặt trực tiếp file APK vào thư mục này để Render lưu trữ và phân phối trực tiếp:
- Tên tệp khuyến nghị: `TienLo-release.apk` hoặc `TienLo.apk`
- Người dùng khi truy cập `https://tienlo.onrender.com/download` sẽ tải trực tiếp file này về máy.
- Hoặc bạn có thể truy cập trang web quản trị bí mật tại `https://tienlo.onrender.com/admin/upload` để tải file APK lên từ trình duyệt.
