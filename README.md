> **"Phàm nhân nhập đạo, lấy kỷ luật làm đan điền, lấy kiên trì luyện thần hồn."**  
> **Tiên Lộ (TienLo)** là ứng dụng phát triển bản thân, theo dõi thói quen và mục tiêu hàng ngày được **Game hóa (Gamification)** sâu sắc theo thế giới quan **Tu Tiên Huyền Huyễn**. Biến từng trang sách, giờ rèn luyện thể chất, cốc nước uống hay giấc ngủ điều độ thành những luồng linh lực giúp đạo hữu đột phá cảnh giới từ Phàm Nhân đến Phi Thăng!

---

## 🔮 TÍNH NĂNG NỔI BẬT

### 1. 🤖 Phân Tích Mục Tiêu Bằng Trí Tuệ Nhân Tạo (Gemini AI)
- Nhập bất kỳ khẩu quyết / mục tiêu đời thực nào (ví dụ: *"Chạy bộ 5km mỗi ngày trong 1 tháng"*, *"Đọc sách 30 phút buổi tối"*...).
- Hệ thống AI (tích hợp **Google Gemini Flash**) tự động bóc tách lộ trình thời gian, phân cấp độ khó (**Dễ, Vừa, Khó, Đột Phá**), đồng thời ban phát lượng **Linh Lực (EXP)** và **Linh Thạch** xứng đáng.

### 2. ⚡ Hệ Thống Cảnh Giới 10 Bậc & Thuật Toán Thăng Tiến
- Mô phỏng chân thực hệ thống tu chân kinh điển:
  1. **Phàm Nhân** (1.000 EXP - Đột phá ngộ đạo)
  2. **Luyện Khí** (10 Tầng: 1.000 → 6.050 EXP)
  3. **Kết Đan** (10 Tầng: 7.500 → 44.150 EXP)
  4. **Nguyên Anh** (10 Tầng: 55.000 → 323.350 EXP)
  5. **Hóa Thần** (10 Tầng: 400.000 → 2.351.900 EXP)
  6. **Luyện Hư** (10 Tầng: 3.000.000 → 17.638.150 EXP)
  7. **Đại Thừa** (10 Tầng: 22.000.000 → 129.346.400 EXP)
  8. **Hợp Thể** (10 Tầng: 160.000.000 → 940.701.800 EXP)
  9. **Độ Kiếp** (10 Tầng: 1.200.000.000 → 7.055.263.300 EXP)
  10. **Phi Tiên** (Cực Cảnh Viên Mãn)
- Thuật toán EXP lũy tiến mềm (`x1.1` → `x1.35`), vừa tạo động lực duy trì hàng ngày vừa giữ giá trị thử thách lâu dài.

### 3. 🛡️ Quy Tắc Trừng Phạt (Tâm Ma Xâm Nhập - Giới Hạn 24h)
- Kỷ luật nghiêm minh: Nếu nhiệm vụ hôm trước không hoàn thành, sáng hôm sau hệ thống sẽ tự động kích hoạt **Cảnh Báo Tâm Ma**.
- **Quy tắc trừ điểm công bằng**: Nhiệm vụ càng khó thì khi bỏ lỡ bị trừ ít điểm hơn (Khó: -50 EXP, Vừa: -80 EXP, Dễ: -120 EXP).
- **Trần phạt tối đa**: Không bao giờ trừ quá **300 EXP/ngày**.
- **Bảo tồn đạo tâm**: Tuyệt đối **không** reset Linh Thạch tích lũy và **không** xóa Chuỗi ngày tu luyện (Streak) khi bị phạt.

### 4. 💎 Điểm Danh Nhận Thưởng & Thu Hoạch Linh Thạch
- Đạo hữu điểm danh mỗi ngày để duy trì Chuỗi ngày liên tiếp (Streak) và nhận linh thạch tích lũy.
- Tích lũy linh thạch để chuẩn bị cho các đợt bế quan và tính năng Dược Phường / Tàng Kinh Các trong tương lai.

### 5. ⏳ Màn Hình Chờ Khởi Động Máy Chủ (Thức Tỉnh Linh Mạch)
- Do backend lưu trữ trên dịch vụ đám mây miễn phí (Render Cloud Free Tier) có cơ chế "ngủ đông" khi không hoạt động, ứng dụng trang bị màn hình chờ với giao diện huyền bí cùng font chữ *Playfair Display*.
- Client tự động thăm dò kết nối (health check) liên tục đến khi máy chủ sẵn sàng sẽ tự động chuyển vào màn hình chính mà không bắt người dùng phải thao tác lại.

## 🚀 HƯỚNG DẪN KHỞI CHẠY DỰ ÁN

### 1. Yêu cầu môi trường
- Node.js $\ge$ 18.x & npm $\ge$ 9.x
- Flutter SDK $\ge$ 3.24.x
- Android Studio / VS Code (với Flutter & Dart extension)

---

### 2. Cài đặt Dependencies

Tại thư mục gốc dự án:
```bash
# Cài đặt backend dependencies
npm --prefix apps/backend install

# Cài đặt frontend dependencies
cd apps/frontend && flutter pub get && cd ../..
```

---

### 3. Cấu hình Biến Môi Trường (`.env`) cho Backend

Tạo file `apps/backend/.env` từ file mẫu:
```bash
cp apps/backend/.env.example apps/backend/.env
```

Cấu hình các tham số:
```env
PORT=3000

# Supabase PostgreSQL
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-supabase-service-role-key

# Firebase Admin SDK (Xác thực Google)
FIREBASE_PROJECT_ID=your-firebase-project-id
FIREBASE_CLIENT_EMAIL=your-firebase-service-account-email
FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"

# Google Gemini AI
GEMINI_API_KEY=your-gemini-api-key
```

---

### 4. Khởi chạy Chế độ Phát triển (Dev Mode)

#### Chạy Backend:
```bash
npm run dev:be
```
- API Endpoint cục bộ: `http://localhost:3000/api`
- Kiểm tra sức khỏe: `http://localhost:3000/api/health`

#### Chạy Flutter App:
```bash
# Chạy trực tiếp trên máy ảo hoặc thiết bị cắm dây
npm run dev:fe

# Hoặc bằng lệnh Flutter
cd apps/frontend
flutter run
```

> **Ghi chú**: Ở chế độ Debug (`flutter run`), ứng dụng sẽ tự động trỏ về `http://10.0.2.2:3000/api` (Android Emulator) hoặc `http://localhost:3000/api`. Khi đóng gói bản phát hành (Release APK), ứng dụng tự động kết nối máy chủ Render đám mây: `https://tienlo.onrender.com/api`.

## 📦 ĐÓNG GÓI BẢN PHÁT HÀNH (BUILD RELEASE APK)

Ứng dụng đã được tối ưu hóa toàn diện, tuân thủ font tree-shaking và cấp quyền mạng `INTERNET` trong `AndroidManifest.xml`.

Để build file APK Release cài đặt trực tiếp lên điện thoại Android:

```bash
cd apps/frontend
flutter build apk --release
```

Sau khi hoàn tất, file APK sẽ nằm tại:
```text
apps/frontend/build/app/outputs/flutter-apk/app-release.apk
```

Đạo hữu có thể sao chép file này vào điện thoại hoặc phát hành thông qua mục **GitHub Releases**.

## 📡 DANH SÁCH API ENDPOINTS CHÍNH

### Hệ thống & Sức khỏe:
- `GET /api/health` - Trả về trạng thái hoạt động của máy chủ (phục vụ Cold-Start check).

### Xác thực & Người dùng:
- `POST /api/auth/sync` - Đồng bộ người dùng từ Firebase Auth vào Supabase database.
- `GET /api/users/profile` - Lấy thông tin tài khoản người dùng hiện tại.

### Tu Tiên & Cảnh Giới:
- `GET /api/cultivation/profile` - Lấy thông tin cảnh giới, điểm linh lực, linh thạch, chuỗi ngày tu luyện.
- `POST /api/cultivation/check-in` - Điểm danh tu luyện hàng ngày, nhận thưởng và tăng streak.
- `POST /api/cultivation/claim-quest-xp` - Nhận linh lực và linh thạch khi hoàn thành nhiệm vụ.
- `POST /api/cultivation/penalty` - Áp dụng phạt suy giảm tu vi khi chưa hoàn thành nhiệm vụ ngày trước.

### Nhiệm Vụ & Trí Tuệ Nhân Tạo:
- `POST /api/campaigns/analyze` - Gửi khẩu quyết mục tiêu để Gemini AI sinh chuỗi nhiệm vụ tu luyện.
